# Sammiie (سمی) — فروشگاه آنلاین عروسک‌های بافتنی و نقاشی

فروشگاه فارسی و راست‌به‌چپ با پنل مدیریت کامل. پرداخت فعلاً **کارت‌به‌کارت با تایید دستی** است و درگاه
زرین‌پال از قبل در کد آماده است تا هر وقت مرچنت گرفتی فقط روشنش کنی.

ساختار و الگوهای امنیتی از SentinelWeb (Flask، پنل جدا با ورود دومرحله‌ای، گزارش فعالیت، CSRF، محدودیت نرخ)
و روش استقرار از Paradigmshift (Docker روی پارس‌پک با دیسک ماندگار) گرفته شده است.

## امکانات

**فروشگاه:** صفحه اصلی با هیرو شب‌وماه، دسته‌بندی، جستجو، مرتب‌سازی، فیلتر موجودها، صفحه محصول با گالری عکس،
گالری نقاشی‌ها، سبد خرید، کد تخفیف، ارسال رایگان بالای مبلغ مشخص، فرم نشانی با اعتبارسنجی موبایل و کد پستی،
صفحه سفارش با شماره کارت (دکمه کپی) و بارگذاری رسید، پیگیری سفارش با کد + موبایل، تماس، خبرنامه، sitemap و robots.

**پنل مدیریت** (`/manage` یا هر مسیری که در `ADMIN_PATH` بگذاری):
- داشبورد: رسیدهای منتظر تایید، آماده‌ی ارسال، نمودار فروش ۱۴ روز، موجودی کم
- محصولات: افزودن/ویرایش همه‌ی مشخصات (قیمت، قیمت قبل از تخفیف، موجودی، سفارش ساخت، زمان ساخت، اندازه، وزن،
  جنس، رنگ، نگهداری، کلیدواژه، SKU، ویژه، پنهان)، چند عکس با ترتیب‌دهی و انتخاب عکس اصلی، ویرایش سریع قیمت و
  موجودی از جدول، کپی و حذف امن
- دسته‌بندی‌ها، کدهای تخفیف (درصدی/مبلغی، حداقل خرید، سقف استفاده، تاریخ انقضا)
- سفارش‌ها: فیلتر وضعیت، دیدن رسید، **تایید یا رد پرداخت با دلیل**، تغییر وضعیت، کد رهگیری پست، یادداشت داخلی،
  فاکتور قابل چاپ، خروجی CSV، لغو سفارش‌های پرداخت‌نشده (موجودی برمی‌گردد)
- پیام‌ها و مشترکین خبرنامه، تنظیمات فروشگاه/پرداخت/ارسال، مدیران و ورود دومرحله‌ای، گزارش فعالیت

## روند کارت‌به‌کارت

۱. مشتری سفارش می‌دهد → کالا رزرو می‌شود (وضعیت «در انتظار پرداخت»).
۲. شماره کارت و مبلغ را می‌بیند، واریز می‌کند، ۴ رقم آخر کارت + شماره پیگیری + عکس رسید را ثبت می‌کند.
۳. تو در پنل، واریز را در اپ بانک چک می‌کنی و «تایید» یا «رد با دلیل» می‌زنی. با رد، مشتری می‌تواند رسید درست را دوباره بفرستد.
۴. بعد از ارسال، کد رهگیری پست را وارد می‌کنی تا مشتری در صفحه سفارش ببیند.

رسیدها خصوصی‌اند و فقط برای مدیر وارد شده نمایش داده می‌شوند.

## اجرای محلی

```bash
pip install -r requirements.txt
cp .env.example .env        # SECRET_KEY را عوض کن؛ برای محلی DATABASE_URL و MEDIA_ROOT را پاک کن
flask --app wsgi seed       # ۵ دسته و ۶۹ محصول از پوشه seed/
flask --app wsgi create-admin mahdi
flask --app wsgi run
```
سایت: http://127.0.0.1:5000 — پنل: http://127.0.0.1:5000/manage

تست‌ها: `python -m pytest -q`

## استقرار روی پارس‌پک (Docker)

۱. یک دیسک ماندگار به مسیر `/data` وصل کن (دیتابیس SQLite و عکس‌ها آنجا می‌مانند).
۲. متغیرهای `.env.example` را در تنظیمات اپ وارد کن؛ حتماً `SECRET_KEY`، `ADMIN_PATH`، `PUBLIC_BASE_URL`.
۳. برای ساخت اولین مدیر، `ADMIN_USERNAME` و `ADMIN_PASSWORD` را بگذار، یک بار اجرا کن، بعد `ADMIN_PASSWORD` را پاک کن.
۴. پورت ۸۰۰۰ است. برای لغو خودکار سفارش‌های بدون رسید، روزانه `flask --app wsgi expire-orders` را اجرا کن (یا از دکمه‌ی پنل).

## روشن‌کردن درگاه زرین‌پال

`ZARINPAL_MERCHANT_ID` و `PUBLIC_BASE_URL` را تنظیم کن، با `ZARINPAL_SANDBOX=1` کل مسیر را تست کن، بعد در
«پنل ← پرداخت و درگاه» تیک درگاه را بزن. کد در `app/payments/zarinpal.py` است؛ درگاه دیگر = یک فایل provider جدید.
